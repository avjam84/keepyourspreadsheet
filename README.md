# KeepYourSpreadsheet

Static site generated by `build.py` into `./public`.

## Deploying (GitHub Pages — target host)
Repo: https://github.com/avjam84/keepyourspreadsheet (to be created)
Live: https://avjam84.github.io/keepyourspreadsheet/

Edit `build.py`, commit, `git push origin main`. The workflow in
`.github/workflows/pages.yml` rebuilds with the correct base URL and deploys `./public`.
In repo Settings → Pages, set Source = "GitHub Actions" (the workflow also tries to enable it).

## Local preview
python3 build.py http://localhost:8000 && python3 -m http.server -d public 8000
